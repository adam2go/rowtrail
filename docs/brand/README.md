# Meet Trail / 小迹

![Trail, three mint data rows following orange stepping stones.](trail.png)

Trail is RowTrail's small, curious companion. Three rounded data rows make one
body; a tail and orange stepping stones turn each saved result into a path to
the next question. The Chinese name **小迹** means a little trace or trail.

The project promise is **Explore data. Keep the trail.**
In Chinese: **探索数据，留下可继续的足迹。**

## Assets and use

- [`trail.png`](trail.png): the original selected transparent PNG, 2,172 × 724,
  517,477 bytes. Suitable for the README or a project introduction.
- [`prompt.txt`](prompt.txt): the complete image-generation prompt.
- Palette: deep pine `#123C35`, mint `#8DD9BE`, orange `#F5A33B`, warm cream
  `#FBF8F1`. These are supporting design colors, not measured pixel values.

Keep the whole character and its trail visible, leave breathing room, and provide
alt text. Markdown carries the title and explanatory text so it remains selectable,
translatable and accessible. There is no text baked into the illustration.
